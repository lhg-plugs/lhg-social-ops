# lhg-so-positioning：账号定位

> 目标：一句话说清"我是谁、给谁、解决什么"。
> 核心纪律：**定位是宪法，日历、选题、复盘都不得违宪。**

## 1. 何时使用

- 新开账号 / 接手老账号重做，第一步永远是定位
- 内容做了三个月没起色，回来查定位（大概率是定位错了，不是执行错了）
- 用户说"帮我规划一下账号"但没说清给谁看时 → 先跑本 skill

## 2. 输入与输出

- **输入**：账号/品牌的一句话描述（可能很模糊）
- **输出**：账号定位卡（见第 5 步模板），用户确认后存档为 `positioning.md`

## 3. 第一步：三问澄清

一次问 1-2 个，先开放后收敛。每个问题的"好答案"长什么样，直接给用户示范：

### 问 1：给谁看？（人群）
- ❌ 差答案："年轻人""大众""对财经感兴趣的人"
- ✅ 好答案："25-35 岁、一线城市、刚有娃的妈妈，焦虑教育投入"
- 追问技巧：能说出"他现在关注了谁"吗？说不出来，人群就是假的。

### 问 2：解决什么问题？（价值）
三选一为主，不许"都要"：
- **信息差**：我知道你不知道的（行业内幕、政策解读）
- **技能**：我会你不会的（教程、拆解、避坑）
- **情绪价值**：陪伴、认同、爽感（故事、观点、玩梗）
- 检验：用户关注你 30 天后，能说出"因为你我学会了/知道了/感觉___"吗？说不出，价值就是空的。

### 问 3：和别人有什么不一样？（差异化）
- 同类账号列 3-5 个，一个一个问"它和你的区别是什么"。
- 差异化只能有**一个主打**（其他的降为次打）：主打是用户向别人介绍你时会说的那句话。
- 检验：把你的差异化遮住账号名，放到同类账号里还能认出来吗？认不出，重写。

### 对标表：同类账号拆解

问差异化之前，先把同类账号拆了（3-5 个，填表）：

| 账号 | 人群 | 主价值 | 差异化 | 我能抄什么 | 我要避开什么 |
|---|---|---|---|---|---|
| <账号A> | | | | | |
| <账号B> | | | | | |

填完这张表，差异化基本就出来了：大家都做的 = 入场券（你也得有）；都没做好的 = 机会；做法分岔的 = 你必须选边站。**差异化不是想出来的，是对比出来的。**

## 4. 第二步：写定位卡

### 一句话定位（30 字以内，铁律）
公式：`我是<身份>，帮<人群>解决<问题>`。
- ✅ "前券商分析师，帮小白看懂财报里的坑"
- ❌ "分享财经知识干货的博主"（换个账号也成立 = 泛）

### 内容支柱（3-4 个，配占比）
每个支柱：名字 + 占比 + 一句话说明 + 举例选题。
- 占比总和 100%，且 4 周内每个支柱至少出现 2 次（防跑偏）。
- 支柱之间不许打架（如"深度长文"和"日更短平快"同为支柱 = 打架）。

### 人设与语气
- 人设一句话（如"较真的大哥""温柔但毒舌的学姐"）
- 语气关键词 3 个（如"直接、较真、不端"）
- **绝不说的话** 3 句（如"家人们谁懂啊""绝绝子"——按人设写具体的）

### 不做什么（明确排除，至少 2 条）
- 如：不追社会热点、不接三无产品广告、不做标题党
- 排除项必须是"真实的诱惑"，写"不违法"这种凑数的删掉。

## 5. 第三步：定位卡模板

```markdown
# 账号定位卡（<日期>）
## 一句话定位
<30 字以内>
## 人群画像
- 是谁：
- 在哪（平台+城市层级）：
- 痛点（top 3）：
- 现在关注谁（3-5 个同类账号）：
## 价值主张
- 主价值：<信息差/技能/情绪价值>——<一句话>
## 差异化
- 主打：<一句话>
- 次打：<1-2 个>
## 内容支柱
1. <支柱名>（占比%）：<说明>，如<举例>
## 人设与语气
- 人设：
- 语气关键词：
- 绝不说的话：
## 不做什么
- 
## 有效期
- 本定位卡有效期 6 个月，到期重审（人群和平台会变）
```

## 6. 第四步：压力测试

定位卡写完，逐条过：

1. **泛话测试**：一句话定位遮住账号名放同类里，还能认出来吗？
2. **支柱打架测试**：3-4 个支柱的生产节奏互相冲突吗？
3. **人设一致性测试**："绝不说的话"里的话，过去 10 篇内容里出现过吗？出现过，人设就是假的。
4. **排除项真实性测试**：不做事项里有没有"其实很想做"的？有，说明定位在回避真问题，拿出来谈。

## 7. 定位的保质期与重审信号

- 定位卡有效期 **6 个月**，到期重审。
- 提前重审的信号：连续 4 周数据下滑且复盘归因到"人群变了"；平台规则大变；账号转型。
- 重审不是重写：先看是定位错了还是执行错了，80% 的情况是执行没做到位。

## 8. 反模式（不要这么做）

- ❌ 人群写"年轻人""大众"——等于没写
- ❌ 价值"都要"（信息差+技能+情绪价值全要）——全要等于全不要
- ❌ 差异化写 3 个主打——主打只能有一个
- ❌ 一句话定位 50 字——30 字以内，超了就是没想清楚
- ❌ 定位卡不给用户确认——定位是契约，用户没点头，后面全白做
- ❌ "不做什么"写"不违法不违规"——凑数，删掉

## 9. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. 三问都问了吗？有没有替用户脑补答案？→ 脑补的下次必须问。
2. 一句话定位 30 字以内吗？泛话测试过了吗？→ 没过重写。
3. 差异化主打只有一个吗？→ 多了就砍。
4. 定位卡用户确认了吗？→ 未经确认不许进日历。

如发现本 skill 自身的方法论缺陷，按以下流程反馈：

- **标准冒烟用例**：用"一个讲 A 股财报的抖音号"走一遍本 skill，检查三问是否收敛、一句话定位是否 ≤30 字、支柱是否不打架。
- **一键提 issue**：确认问题后，以 `[QC] <一句话问题>` 为标题、正文写清"复现输入 → 错误输出 → 期望输出"，提交到 https://github.com/lhg-plugs/lhg-social-ops/issues。
